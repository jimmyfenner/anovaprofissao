Política de Privacidade do Publicador

Esta política vale para o Publicador Jimmy Fenner, a ferramenta pessoal que publica e agenda vídeos no canal de YouTube do Jimmy Fenner. Ela explica quais dados o Publicador acessa, onde eles ficam e como revogar o acesso.

1. Uso dos Serviços de API do YouTube

O Publicador usa os Serviços de API do YouTube (YouTube Data API v3). Ao usá-lo, você também está sujeito à Política de Privacidade do Google e aos Termos de Serviço do YouTube.

2. Quem usa e quem é o responsável

O Publicador tem um único usuário: Jimmy Fenner, que é também o responsável por ele. Funciona só no computador dele e só para o canal dele. Contato: contato@jimmyfenner.com.br.

3. Quais dados o Publicador acessa

Depois que o Jimmy autoriza o acesso na tela de permissão do Google, o Publicador:

  • lê o nome, o identificador e as estatísticas públicas do canal autorizado (inscritos, visualizações e quantidade de vídeos), para confirmar que está no canal certo;
  • envia vídeos para esse canal, com título, descrição, tags e configurações escritos pelo Jimmy;
  • altera o status e o horário de publicação dos vídeos que ele mesmo enviou.

O Publicador não lê comentários, mensagens, dados de inscritos, histórico de visualização nem dados de outros canais.

4. Onde os dados ficam

  • Autorização do Google: o token de acesso fica guardado num arquivo protegido no computador do Jimmy. Não é enviado a nenhum servidor além dos do próprio Google.
  • Registro das publicações: o identificador, o link e o horário agendado de cada vídeo enviado ficam num arquivo local, no mesmo computador.
  • Estatísticas do canal: são mostradas na tela e não são guardadas.

O Publicador não tem servidor próprio, não usa banco de dados externo e não grava cookies nem outras informações no navegador ou no aparelho de terceiros.

5. Compartilhamento

Os dados obtidos pela API do YouTube não são vendidos, alugados nem compartilhados com ninguém, e não são usados para publicidade. Eles só trafegam entre o computador do Jimmy e os servidores do Google, para fazer o que está descrito acima. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

6. Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google. Depois da revogação, o token guardado deixa de funcionar e o arquivo pode ser apagado. O registro local das publicações pode ser apagado a qualquer momento. Os vídeos publicados continuam no canal e são gerenciados pelo próprio YouTube.

7. Mudanças nesta política

Se o Publicador passar a acessar outros dados ou a guardá-los de outra forma, esta página será atualizada antes, com nova data de revisão.

Privacy Policy (English)

This policy covers Publicador Jimmy Fenner, a personal tool that uploads and schedules videos on Jimmy Fenner's own YouTube channel.

YouTube API Services. Publicador uses the YouTube API Services (YouTube Data API v3). By using it, you are also bound by the Google Privacy Policy and the YouTube Terms of Service.

Who uses it. Publicador has a single user, Jimmy Fenner, who is also responsible for it. It runs only on his computer and only for his channel. Contact: contato@jimmyfenner.com.br.

Data accessed. After authorization on Google's consent screen, Publicador reads the authorized channel's name, ID and public statistics (subscribers, views and video count) to confirm it is the right channel; uploads videos to that channel with the title, description, tags and settings written by Jimmy; and changes the privacy status and publication time of the videos it uploaded. It does not read comments, messages, subscriber data, watch history or data from other channels.

Storage. The Google authorization token is kept in a protected file on Jimmy's computer and is never sent anywhere other than Google's own servers. The ID, link and scheduled time of each uploaded video are kept in a local file on the same computer. Channel statistics are displayed and not stored. Publicador has no server of its own, uses no external database and does not store cookies or any other information on anyone's browser or device.

Sharing. Data obtained through the YouTube API is not sold, rented or shared with anyone, and is not used for advertising. It only travels between Jimmy's computer and Google's servers. Publicador's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data. Access can be revoked at any time on the Google security settings page. After that, the stored token stops working and its file can be deleted. The local publication record can be deleted at any time. Published videos stay on the channel and are managed by YouTube.

Changes. If Publicador starts accessing other data or storing it differently, this page will be updated first, with a new revision date.
