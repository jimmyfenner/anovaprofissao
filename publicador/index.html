Publicador Jimmy Fenner

Ferramenta pessoal que publica e agenda os vídeos do canal de YouTube do próprio Jimmy Fenner, @jimmyfenner, a partir do computador dele.

O que ele faz

  • Envia para o canal os vídeos que o Jimmy já editou, com o título, a descrição e as tags que ele mesmo definiu.
  • Agenda o horário de publicação de cada vídeo.
  • Consulta o nome e as estatísticas públicas do canal, para confirmar que está publicando no canal certo.

Quem usa

Só o Jimmy Fenner, no próprio computador, para o próprio canal. Não é um serviço aberto ao público, não tem cadastro de usuários e não acessa o canal de mais ninguém.

Como funciona

O Publicador usa os Serviços de API do YouTube (YouTube Data API v3). O acesso ao canal é autorizado pelo próprio Jimmy na tela de permissão do Google e pode ser revogado a qualquer momento nas permissões da Conta do Google. A autorização fica guardada apenas no computador dele.

In English

Publicador Jimmy Fenner is a personal tool that uploads and schedules videos on Jimmy Fenner's own YouTube channel (@jimmyfenner) from his computer. It uses the YouTube API Services (YouTube Data API v3) to upload his edited videos with the title, description and tags he wrote, to schedule their publication time, and to read his channel's name and public statistics.

It has a single user, Jimmy Fenner. It is not offered to the public, has no user sign-up and never accesses anyone else's channel. Access is granted through Google's consent screen and can be revoked at any time in the Google Account permissions page. See the Privacy Policy and the Terms of Use.
