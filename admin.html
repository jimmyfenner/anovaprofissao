Vídeos e contato

Cole o link do YouTube ou do Vimeo e escolha o formato. Ao clicar, o vídeo abre em tela cheia no formato certo. Deixando vazio, o espaço reservado continua aparecendo.

A versão longa, ao lado do resumo. Gravou uma nova? É só trocar o link aqui; a duração aparece sozinha.
Código do país + DDD + número, só dígitos.
Minutos e segundos do vídeo, como 2:30. O contador acompanha a reprodução de verdade — se a pessoa pausar, ele pausa junto.

Um pixel só para o site todo. Vazio = nenhum script da Meta é carregado. Eventos enviados: PageView em toda visita, Lead quando alguém termina a avaliação de perfil e CompleteRegistration quando vai para o cadastro direto.

Para quem chega decidido. Confira se o seu ID está no link.
Aparece só para quem diz que hoje não consegue investir mas pretende entrar mais pra frente. Prefira um canal: em grupo, todos os seus leads veem o número uns dos outros. Vazio = o convite não aparece.
